# `pages` Folder

This folder contains all Streamlit pages for the EuroHome application, organized by user persona. Pages are prefixed with a number to control their order in the sidebar.

## General Pages
- `Home.py` — landing page with EuroHome animation and login selection by persona
- `About.py` — project description and team profiles

## Student Persona
- `00_Student_home.py` — student dashboard
- `01_view_listings_student.py` — browse and filter EU housing listings
- `02_view_saved_listings.py` — view saved/favorited listings
- `03_view_reviews.py` — view reviews for a listing
- `04_student_pred.py` — housing satisfaction predictor

## Real Estate Agent Persona
- `05_REA_agent_home.py` — real estate agent dashboard
- `06_market_dashboard.py` — EU housing market trends
- `07_view_listings_rea.py` — view and manage listings
- `08_add_listing.py` — create a new listing

## Government Agency Persona
- `10_GA_home.py` — government agency dashboard
- `11_view_funding.py` — explore EU funding programs
- `12_risk_heatmap.py` — interactive social indicator risk map
- `13_funding_drafts.py` — view and manage funding drafts
- `14_government_pred.py` — housing deprivation predictor
- `15_create_funding_draft.py` — propose a new funding plan
